# Scripts Notes

This folder contains local start and stop scripts for the Dockerized MVP.

- `start-mac.sh` and `stop-mac.sh` are for macOS.
- `start-linux.sh` and `stop-linux.sh` are for Linux.
- `start-windows.ps1` and `stop-windows.ps1` are for Windows PowerShell.

All scripts run from the project root and use `docker compose`.
